Mes projets

Night Watch

Démo d’un jeu vidéo mélant plateforme et speedrun ou le joueur devra finir le niveau le plus rapidement possible. J’ai réalisé le jeu entièrement seul, la plupart des assets graphiques on été trouvé, acheté sur itch.io. Le jeu a été réalisé avec Unity 3D et il est possible d’y jouer a la manette comme au clavier.
Le jeu est disponnible sur Windwos et linux sur ma page itch.io.

Application de suivi de poisson

Durant de mon stage pour le CIRAD,Centre de coopération internationale en recherche, j’ai pu pu déveloper d’une application ayant pour but de suivre les poissons dans leurs aquarium afin de calculer la nouriture qu’ils mangent pour determiner et selectionner les individues qui convertise le mieux la nouriture en biomasse.
J’ai utilisé YOLO, You Look Only Once, qui est une framework de machine learning, permetant la détection d’objet dans une image a partir d’un dataset que j’ai élaboré.

Pokemon Gym Challenge

Maquette d’un jeu d’enigme réalisé avec les assets des jeux Pokemons. Le joueur doit atteindre la fin de l’arène en marchant uniquement une fois sur la glace qui lui fait face, s’il marche a nouveau sur la galce elle se brise et le joueur devra recommencer. la maquette est jouable directement via un navigateur sur ma page itch.io.
les sources du jeu sont disponnible sur git hub.

Train On My Puzzle

Petit jeu vidéo réaliser lors du cours Jeu Serieux à la faculté des sciences de montpellier. Train On My Puzzle est un jeu de puzzle ou le joueur devra compléter le chemin féroviaire avant que le train ne se crash. Le jeu comporte un niveau ainsi qu’un mode de jeu ou le puzzle est généré procéduralement.
